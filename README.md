# ThermoChain 
 
 ThermoChain é um projeto de registro de temperatura desenvolvido com foco em controle e segurança de dados em toda a cadeia de vacinas contra a febre amarela. A solução utiliza sensores para coletar informações, integrando hardware, com um sistema web e banco de dados. Nosso objetivo é permitir o registro das variações de temperatura, auxiliando na tomada de decisões e evitando perdas em ambientes que exigem controle térmico, como é o caso de armazenamento de vacinas. O projeto também conta com DashBoard para visualização dos dados de forma prática e análise de indicadores.
