# 🌡️ ThermoChain

> Controle térmico inteligente de ponta a ponta para vacinas

---

## 📌 Sobre o Projeto

O **ThermoChain** é um sistema desenvolvido para monitorar a temperatura de vacinas ao longo de toda a cadeia de frio — desde a indústria até o paciente final.

O objetivo principal é garantir a integridade dos imunobiológicos, evitando perdas causadas por variações térmicas e assegurando conformidade com normas regulatórias.

---

## 🚨 Problema

A falta de monitoramento contínuo na cadeia de frio pode causar:

* ❌ Perda de até **41,4% das vacinas**
* 💸 Prejuízos milionários (até **R$ 50 milhões/ano** no setor privado)
* ⚠️ Riscos à saúde pública
* 📉 Perda de credibilidade de empresas farmacêuticas

---

## 🎯 Objetivos

* Gerar **insights**
* Emitir **alertas preventivos**
* Reduzir perdas de vacinas

---

## 🧠 Como funciona

1. Sensores capturam a temperatura
2. Dados são enviados para a plataforma
3. Sistema analisa em tempo real
4. Alertas são gerados em caso de risco
5. Relatórios garantem rastreabilidade completa

## 🧩 Metodologia

O projeto foi desenvolvido utilizando **Scrum**, uma metodologia ágil baseada em ciclos curtos chamados *sprints*. Cada sprint envolve planejamento, desenvolvimento, testes e revisão, permitindo entregas contínuas e melhorias constantes.

Essa abordagem facilita a organização do projeto, melhora a comunicação da equipe e permite identificar problemas rapidamente, tornando o desenvolvimento mais eficiente e adaptável.
