# ThermoChain 
 
A ThermoChain é um projeto de monitoramento de temperatura desenvolvido com foco em controle e segurança de dados. A solução utiliza sensores para coletar informações em tempo real, integrando hardware (como Arduino) com um sistema web e banco de dados. Seu objetivo é permitir o acompanhamento contínuo das variações de temperatura, auxiliando na tomada de decisões e evitando perdas em ambientes que exigem controle térmico, como armazenamento de produtos sensíveis. O projeto também conta com dashboards para visualização dos dados e análise de indicadores.
